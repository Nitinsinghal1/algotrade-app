# AlgoTrade

Downloads and website for AlgoTrade, a Windows app for NIFTY and SENSEX paper and rule-based trading.

- Website: https://nitinsinghal1.github.io/algotrade-app/
- Download the newest version: https://github.com/Nitinsinghal1/algotrade-app/releases/latest/download/AlgoTrade-windows.zip

Unzip the folder and double-click `AlgoTrade.exe`. Nothing else to install.

Trading in futures and options carries a high risk of loss. This is software, not investment advice.
