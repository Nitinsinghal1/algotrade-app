How it works

Four steps, the first three on paper.

Download and open

Unzip the folder and double-click AlgoTrade. The panel opens in your browser. Python and every library are inside the folder.

Connect your broker

Paste your API details and press Save & test. No broker yet? Skip this and practise on past trading days.

Start the engine

With your broker connected it trades in practice mode on the live market; nothing is sent to your broker as an order. Without one it replays a past day.

Read the daily report

After the close you get a score, the day's trades and what went wrong. Go live only when the track record earns it.

Questions

Before you download.

Will it make money?

Nobody can promise that, and we do not. Most simple intraday rules lose money after charges. AlgoTrade is the tool to find that out on paper, with honest numbers, before any real money is involved.

Do you hold my money or my broker password?

No. Your money stays with your broker. Your API keys are stored in a file on your own computer and are never sent to us.

Does it keep running when my PC is off?

No. The engine runs on the computer where you opened the app. For round-the-clock use there is a server mode for a Linux VPS.

Which Windows does it need?

Windows 10 or 11, 64-bit. Python and every library come inside the folder, so there is nothing else to install.

Windows showed a security warning. Is that normal?

From version 1.7 the app starts through the official, signed Python program, so Windows should let it run. If SmartScreen still asks, choose More info, then Run anyway.

Can I trade live with it?

Yes, on the Pro plan, after you switch live mode on in two places. Start with one lot, and only after your practice track record covers enough days to trust it.
